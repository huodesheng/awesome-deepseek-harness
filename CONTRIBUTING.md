# Contributing to Awesome DeepSeek Harness

## How to add a plugin

1. **Check it's not already listed** — search the README first.
2. **Open an Issue** with:
   - Plugin name
   - GitHub repo URL
   - One sentence describing what it does
   - Why it deserves to be on this list (not self-promotion)
3. **Or open a PR** — add one line to the table in README.md, following the existing format.

## Rules

- Must be a **DeepSeek Harness (DSH) plugin** — not a general LLM tool.
- Must have a **public GitHub repo** with clear installation instructions.
- Must be **actively maintained** (commits within last 3 months).
- No self-promotion. If it's your own plugin, disclose it in the PR.
- The list is curated — not everything gets in. Quality over quantity.

## After your PR is merged

The plugin will also be reviewed for inclusion on [harnesscatalog.com](https://harnesscatalog.com) — the companion directory with full reviews and install commands.
